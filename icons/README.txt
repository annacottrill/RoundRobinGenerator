ICON GENERATION INSTRUCTIONS
============================

To generate icons for this PWA:

Option 1: Use the Icon Generator HTML Page
-------------------------------------------
1. Open create-icons.html in your browser
2. Click "Generate Icons"
3. Right-click each icon and save it to this folder with the correct name:
   - icon-72.png
   - icon-96.png
   - icon-128.png
   - icon-144.png
   - icon-152.png
   - icon-192.png
   - icon-384.png
   - icon-512.png

Option 2: Use Online Tools (Recommended for Production)
--------------------------------------------------------
For professional-looking icons, use one of these online tools:

1. PWA Builder Image Generator
   https://www.pwabuilder.com/imageGenerator
   - Upload a 512x512 source image
   - Downloads all required sizes automatically

2. Real Favicon Generator
   https://realfavicongenerator.net/
   - Upload your icon
   - Generates all sizes and formats

Option 3: Create Manually
--------------------------
Design an icon in your favorite graphics tool (Figma, Canva, Photoshop, etc.)
and export at the required sizes listed above.

Icon Guidelines:
----------------
- Use a simple, recognizable design
- Make sure it looks good at small sizes (72x72)
- Use high contrast colors
- Consider a transparent background for iOS
- Keep important elements away from edges (safe zone)

For a team roping app, consider:
- Rope/lasso imagery
- Cowboy hat silhouette
- Horse silhouette
- Simple text (like "RR" for Round Robin)
