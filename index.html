How to Use Round Robin Roping

A complete guide to managing your team roping events from start to finish

What is Round Robin Format?

Round Robin means every header will be paired with every heeler exactly once. This ensures fair competition and allows everyone to rope with each other. The app automatically generates all team pairings and tracks their performance throughout the event.

1

Add Ropers

First, add all participants who will be roping at your event.

Step-by-step:

  1. Click "Manage Ropers" in the navigation menu
  2. In the "Add New Roper" section, enter the roper's name
  3. Select their position: Header or Heeler
  4. Set their skill level (1-10) to help you remember their experience
  5. Click "Add Roper"
  6. Repeat for all participants

Note: You cannot add two ropers with the same name in the same position. Skill levels are for reference only and don't affect team generation.

2

Create Event

Set up your event details and select which ropers will participate.

Step-by-step:

  1. Click "Manage Events" in the navigation menu
  2. Enter an event name (e.g., "Saturday Morning Roping")
  3. Optionally set the event date
  4. Configure penalties if needed (One Leg, Barrier, etc.) - these add seconds to run times
  5. In the "Select Ropers" section, check the boxes for headers who will participate
    • Use the search box to quickly find ropers
    • Click "Select All" to choose all headers at once
    • Click "Add Header" to quickly add a new roper without leaving the page
  6. Repeat for heelers - select which heelers will participate
  7. Review the counter badges showing how many headers and heelers are selected
  8. Click "Generate Event"
  9. The app will automatically create all team pairings (every header with every heeler)

Tip: You need at least one header and one heeler to create an event. With 3 headers and 4 heelers, you'll get 12 teams (3×4).

3

Record Times

Enter run times as teams complete their runs during the event.

Step-by-step:

  1. Click "Record Times" in the navigation menu
  2. Select your event from the dropdown
  3. You'll see all teams that need to run, displayed as cards
  4. For each team that completes a run:
    • Enter the time in seconds (e.g., "8.5" for 8.5 seconds)
    • Check any penalty boxes if applicable (the penalty seconds will be added automatically)
    • Click "Save Time"
  5. Teams with recorded times will show their final time and penalties
  6. Continue recording times as teams complete their runs

Note: You can edit times later by entering a new time and clicking "Save Time" again. The latest time always overwrites the previous one.

4

View Results

Check standings, statistics, and individual roper performance.

Step-by-step:

  1. Click "View Results" in the navigation menu
  2. Select your event from the dropdown
  3. View the standings table showing:
    • Team names (Header + Heeler)
    • Total time (sum of all runs)
    • Average time per run
    • Number of runs completed
  4. Click on a team name to see detailed breakdown of each run with times and penalties
  5. Scroll down to see individual roper statistics showing average performance

Note: Teams are ranked by total time (lowest is best). Results update in real-time as you record new times.

5

Complete Event

Mark the event as finished to keep your event list organized.

Step-by-step:

  1. Stay on "View Results" (or navigate there if you've left)
  2. Make sure your event is selected in the dropdown
  3. Once all runs are recorded, a green banner will appear at the top
  4. Click the "Mark as Completed" button in the banner
  5. Completed events are preserved with all their data but moved to a "completed" state

Alternative: You can also mark events as completed from the "Manage Events" page under "Manage Existing Events."

Manage Ropers

Your roper database. Add, edit, or remove participants.

  • Add Roper: Fill out the form and click "Add Roper"
  • Edit Roper: Click the edit button on any roper, make changes, and save
  • Delete Roper: Click the delete button (existing events won't be affected)
  • View All Ropers: See complete list with position and skill level

Manage Events

Set up new events and manage existing ones.

  • Event Details: Name and optional date
  • Penalties: Configure time penalties (One Leg, Barrier, etc.)
  • Select Ropers: Choose participating headers and heelers with search, select all, and quick add features
  • Generate Event: Creates all team pairings automatically
  • Manage Existing: Edit or mark events as completed

Record Times

Enter run times during the event.

  • Select Event: Choose which event you're recording for
  • Team Cards: Each team is displayed as a card showing the header and heeler
  • Enter Time: Input time in seconds (decimals allowed)
  • Penalties: Check boxes for any penalties incurred
  • Save: Click "Save Time" to record (can be updated later)

View Results

See standings and statistics.

  • Standings Table: Teams ranked by total time (lowest to highest)
  • Team Details: Click team names to see run-by-run breakdown
  • Individual Stats: View average performance for each roper
  • Real-time Updates: Results refresh as new times are recorded

Can I edit an event after creating it?

Yes! Go to "Manage Events" and select the event from "Manage Existing Events." You can change the name, date, or penalties. Warning: Changing participating ropers will regenerate all teams and delete recorded times.

Does this work offline?

Yes! This is a Progressive Web App (PWA) that works completely offline after the initial load. All data is stored locally on your device using IndexedDB.

Can I export my results?

Yes! Go to "View Results", select your event, and scroll to the bottom. Click the purple "Export to CSV" button to download a spreadsheet file with all team standings, times, and individual roper statistics. You can open this file in Excel, Google Sheets, or any spreadsheet program.

Can I add a roper during event creation?

Yes! Click the "Add Header" or "Add Heeler" button below the selection lists. The new roper will be automatically selected for your event.

How do I find ropers in a large list?

Use the search boxes to quickly filter ropers by name. The roper selection areas show up to 10 ropers before scrolling kicks in, and the search works across all ropers.

How do penalties work?

When creating an event, you can configure penalties (e.g., One Leg = 5 seconds). When recording a run, check the penalty boxes and those seconds will be automatically added to the final time.

Can I have duplicate roper names?

You cannot add two ropers with the same name in the same position (e.g., two headers named "John"). However, you can have a header and heeler with the same name.

I accidentally marked my event as completed. How do I reopen it?

No problem! Go to "Manage Events" and select your completed event from "Manage Existing Events" (it will be in the "Completed Events" section of the dropdown). Once selected, click the "Mark as Active" button to reopen it. All your data will still be there.

What if I run out of storage or my data becomes unmanageable?

If you're running low on storage space or your ropers/events list has become too cluttered, you can use the "Clear All Data" option in the navigation menu.

⚠️ CRITICAL WARNING:

  • This action is PERMANENT and CANNOT be undone
  • ALL ropers will be deleted
  • ALL events (active and completed) will be deleted
  • ALL recorded times and results will be deleted
  • Your entire database will be wiped clean

Before clearing: Make sure you've saved any important information elsewhere (screenshots, written notes, etc.). There is no backup or recovery option.

When to use: Use this only when starting fresh, running out of device storage, or when your data has become completely unmanageable. Consider marking old events as "Completed" instead if you just want to organize your active events.

  • • Use meaningful event names with dates (e.g., "Saturday June 15th Roping") to stay organized
  • • Set up all your ropers first, then create events - it's faster
  • • Click "Select All" when most ropers are participating, then uncheck the few who aren't
  • • Mark events as "Completed" when done to keep your active event list clean
  • • Skill levels are just for reference - they don't affect how teams are generated
  • • You can edit roper names or skill levels without affecting existing events
  • • Hover over the info icons throughout the app for quick help on any section
  • • The app works great on phones and tablets - perfect for arena use!

Still Have Questions?

Look for the info icons throughout the app - hover over them for helpful tooltips explaining each section. The app is designed to be intuitive and guide you through each step of the process.
